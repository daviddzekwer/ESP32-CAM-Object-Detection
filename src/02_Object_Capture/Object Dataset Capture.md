# Object Dataset Capture

After successfully setting up the ESP32-CAM, the next stage was collecting images for the machine learning model.

The ESP32-CAM was used to capture images of four target objects:

* Multimeter
* Tester
* Breadboard
* Screwdriver

The collected images formed the dataset that was later uploaded to **Edge Impulse** for labelling and model training.

### Objectives

* Capture images using the ESP32-CAM.
* Collect samples for all four object classes.
* Provide sufficient image variation for model training.
* Prepare the dataset for object detection.

### Outcome

A dataset containing images of the four target objects was collected and prepared for the machine learning workflow.
