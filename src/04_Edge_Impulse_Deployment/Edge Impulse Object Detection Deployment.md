# Edge Impulse Object Detection Deployment

At this stage, the trained machine learning model was deployed to the **ESP32-CAM** using the Arduino-compatible library generated by Edge Impulse.

The model was trained to detect four object classes:

* Multimeter
* Tester
* Breadboard
* Screwdriver

### Machine Learning Workflow

The model was developed through the following process:

**Image Collection → Labelling → Model Training → Evaluation → Deployment**

The trained model achieved approximately:

* **Precision:** 1.00
* **Recall:** 0.95
* **F1 Score:** 97.4%

### Objectives

* Deploy the trained Edge Impulse model to the ESP32-CAM.
* Perform object detection on the embedded device.
* Verify that the model could identify the trained objects.

### Outcome

The Edge Impulse model was successfully integrated with the ESP32-CAM, providing the foundation for the final hardware integration with the LCD and buzzer.
